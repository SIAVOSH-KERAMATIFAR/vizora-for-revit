# Test & Feedback Center contract

The center is a first-class support workflow, not a placeholder tab. It collects structured reproduction data, feature/error/correlation identifiers, sanitized environment data, logs, audit output and user-selected evidence. It never silently uploads data. It emits one consolidated package for a stage and records the package manifest and checksum.

User testing is disabled until Main Install 1 passes every internal Stage 1 gate.
