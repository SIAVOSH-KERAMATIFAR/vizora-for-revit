# Roadmap

## Stage 1 — Foundation + Chair vertical slice

Layered solution, registry, contracts, diagnostics, manifest pipeline, test harness, UI shell, Revit host seam, and one complete Chair asset. Main Install 1 is permitted only after all Stage 1 gates pass.

## Stage 2 — Core content and planning workflows

Expand approved content packs only after first-category direction is approved; implement Selection, Representation, Kitchen, Rooms, Relationships and Custom Assets through isolated contracts.

## Stage 3 — Team, export and release hardening

Shared Library, Export preparation, audit/support workflows, performance, migration, installer hardening and final acceptance.

Revit 2025/2026 are future backports after Revit 2027 stability; they are not current scope.
